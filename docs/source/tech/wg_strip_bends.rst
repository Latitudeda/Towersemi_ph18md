strip_bends.py
======================

Define the bend settings for each waveguide(`Strip.C.WIRE_TE & Strip.C.WIRE_TM & Strip.O.WIRE_TE & Strip.O.WIRE_TM`).

* ``SiN_C_BENDS``

    * ``FOR_WIRE_TE``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 30 um.

    * ``FOR_WIRE_TM``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 90 um.

* ``SiN_O_BENDS``

    * ``FOR_WIRE_TE``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 30 um.

    * ``FOR_WIRE_TM``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 90 um.
